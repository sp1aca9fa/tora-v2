# Decision log

Dated decisions with their reasons, in date order: the record of why Tora is the way it is. It is
append-only: an entry is never edited, and a new entry that replaces an older one names it. What
holds today is in the rules files ([docs/rules](rules/)) and in
[requirements.md](../requirements.md); this file is not where to look up a rule.

New entries go at the end: date, decision, reason. Private specifics (the owner's setup, sources'
quirks) go in the private notes instead.
